# Coordinate Frame (TF) Hierarchy & Specifications

```
map (RTAB-Map SLAM)
 └── odom (robot_localization EKF)
      └── base_footprint (robot ground projection)
           └── base_link (chassis geometric center)
                ├── camera_link
                │    └── camera_link_optical (ROS standard: Z forward, X right, Y down)
                ├── imu_link (accelerometer and gyroscope center)
                ├── left_wheel_link
                ├── right_wheel_link
                ├── front_caster_wheel_link
                └── rear_caster_wheel_link
```

## Frame Definitions
* `map`: Global inertial frame, corrected for loop closures by RTAB-Map.
* `odom`: Continuous local odometric frame generated by the EKF filter. Never jumps.
* `base_footprint`: 2D projection of the robot chassis on the ground plane ($Z = 0$).
* `base_link`: 3D center of the physical chassis.
* `camera_link_optical`: Conforms to ROS optical frame standard ($Z$ pointing outward along camera optical axis, $X$ pointing right, $Y$ pointing down).
